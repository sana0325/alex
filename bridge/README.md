# MT5 Bridge — місток між MetaTrader 5 і Android-додатком

Android-телефон не може напряму керувати MetaTrader 5 — потрібен цей
Python-скрипт, який запускається на тому ж комп'ютері (Windows), де відкритий
термінал MT5, і транслює дані/угоди по Wi-Fi у застосунок.

## Встановлення

1. На комп'ютері з MT5 (Windows, Python 3.10 або 3.11):
   ```
   cd bridge
   pip install -r requirements.txt
   ```
2. Відкрийте MetaTrader 5, увійдіть у торговий рахунок і увімкніть
   **Algo Trading / Автоторгівлю** (кнопка на верхній панелі повинна бути
   зеленою).
3. Запустіть міст:
   ```
   python mt5_bridge.py
   ```
   Побачите `Bridge listening on ws://0.0.0.0:8765`.
4. Дізнайтесь LAN IP цього комп'ютера: `ipconfig` (Windows), рядок
   `IPv4 Address`, напр. `192.168.1.50`.
5. У Android-додатку відкрийте налаштування (⚙) і введіть
   `192.168.1.50:8765` — телефон і комп'ютер мають бути в одній Wi-Fi мережі.

## Що робить міст

- Кожні ~2 секунди читає з MT5 останні M5-свічки, рахує простий об'ємний
  профіль (volume profile) і надсилає в застосунок разом з балансом рахунку
  та списком відкритих позицій бота.
- Приймає з застосунку команди:
  - `OPEN_SPLIT` — відкриває ринковий ордер з SL/TP, розмір лота залежить від
    балансу (та ж драбина, що і в застосунку).
  - `PARTIAL_CLOSE_AND_BU` — закриває ~50% обсягу позиції і переносить SL у
    беззбиток.
  - `CLOSE` — повністю закриває позицію по парі.
- Усі ордери позначені унікальним `magic number` (990022), тому міст ніколи
  не чіпає угоди, відкриті вами вручну.

## Символи брокера

Якщо у вашого брокера символи мають суфікс (напр. `XAUUSD.m`, `EURUSD_i`),
міст сам спробує знайти відповідний символ за префіксом. Якщо визначить
неправильно — відредагуйте словник `SYMBOL_MAP` на початку `mt5_bridge.py`.

## Безпека

- Скрипт торгує реальними/демо грошима на вашому рахунку MT5 — тестуйте
  спершу на демо-рахунку.
- Тримайте порт 8765 доступним лише у своїй локальній мережі. Якщо потрібен
  доступ поза домом — використовуйте VPN/тунель (наприклад Tailscale), а не
  відкривайте порт напряму в інтернет через роутер.
