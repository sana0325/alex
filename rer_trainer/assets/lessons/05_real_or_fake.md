# Справжній сигнал чи фейк

> Противник може застосовувати імітатори та приманки, щоб відволікти засоби розвідки, приховати справжні цілі або змусити витратити ресурси. Завдання оператора — помітити, що сигнал «поводиться неприродно».

## Види імітаційних сигналів

**Імітатори та маяки-приманки.** Нерухомі передавачі, що відтворюють сигнал, схожий на канал керування, відео чи телеметрію БПЛА.

**Повтор записаного сигналу (replay).** Раніше записаний справжній сигнал відтворюється знову. Форма на спектрі правильна, але вміст пакетів не змінюється.

**Сигнали без реального носія.** Передавач є, а БПЛА, якого він нібито обслуговує, немає. Інший варіант — сигнал іде з точки, де нічого не спостерігається.

**GNSS-спуфінг** (з погляду виявлення). Підробні сигнали супутникової навігації. Ознаки: аномально високий рівень сигналів GNSS (справжні сигнали з орбіти дуже слабкі), однакові рівні всіх «супутників», раптові стрибки координат або часу, невідповідність координат від різних джерел.

## Ознаки для розрізнення

| Ознака | Справжній сигнал | Імітація |
|---|---|---|
| Стабільність рівня | «дихає»: завмирання, зміна орієнтації антен | рівний з точністю до десятих дБ |
| Стабільність частоти | невеликий дрейф, особливо при зміні температури | ідеально стала |
| Періодичність | є розкид інтервалів (джитер) | ідеально однакові інтервали |
| Реакція на рух | рівень і пеленг змінюються разом з рухом цілі | нічого не змінюється |
| Рівень і відстань | рівень зростає при наближенні й падає при віддаленні | рівень стрибає ступенями при незмінній відстані |
| Пеленги | з різних постів сходяться в місці цілі | сходяться деінде або не сходяться взагалі |
| Вміст пакетів | змінюється (координати, висота, заряд) | повторюється побітово |
| Ширина смуги | відповідає заявленому типу | «не та» ширина для такого типу |

## Як діяти

1. **Не робіть висновків з однієї ознаки.** Шукайте збіг двох-трьох.
2. **Порівнюйте з іншими джерелами**: візуальне спостереження, сусідні пости, радіолокація.
3. **Дивіться в часі.** Імітація найчастіше видає себе саме поведінкою, а не формою на спектрі.
4. **Фіксуйте спостереження** (час, частота, рівень, пеленг), щоб їх можна було перевірити.

## Тренажер «Знайди фейк»

На вкладці **«Знайди фейк»** ви побачите три сигнали поруч на одному водоспаді та «журнал вимірювань» кожного. Один із них — імітація.

1. Оберіть підозрілий сигнал.
2. Оберіть пояснення, чому саме він.
3. Натисніть **«Перевірити»**.

Деякі ознаки видно прямо на водоспаді: рівний колір без завмирань, ідеальний пунктир, вузька смуга. Інші — лише в журналі вимірювань.
