# РЕР-Тренажер

Офлайн навчальний застосунок для підготовки операторів радіоелектронної розвідки. Він вчить читати водоспад і спектрограму, розпізнавати типи сигналів, відрізняти справжні сигнали від імітаційних і розуміти пеленгування.

Застосунок суто навчальний. Усі сигнали синтетичні й генеруються в ньому самому. З реальним радіообладнанням він не працює.

## Збірка

Готові збірки викладає GitHub Actions: вкладка **Actions** → workflow «РЕР-Тренажер — збірка» → потрібний запуск → блок **Artifacts**.

| Артефакт | Вміст |
|---|---|
| `rer-trainer-android-apk` | `app-release.apk` для встановлення на телефон |
| `rer-trainer-windows` | тека з `rer_trainer.exe` |
| `rer-trainer-linux` | тека з виконуваним файлом `rer_trainer` |

Локальна збірка (потрібен Flutter stable):

```bash
cd rer_trainer
flutter pub get
flutter analyze
flutter test
flutter run -d windows        # або linux, або підключений Android
flutter build apk --release
```

## Що всередині

| Модуль | Інтерактив | Тест |
|---|---|---|
| 1. Основи радіо | калькулятор λ, dBm ↔ мВт, SNR | 9 питань |
| 2. Водоспад і спектрограма | симулятор: сигнали, БПФ, палітра, рівні, усереднення | 8 питань |
| 3. Атлас сигналів | 8 карток із живим синтетичним водоспадом | 8 питань |
| 4. Mesh-мережі БПЛА | карта вузлів, відмова вузла, перебудова маршрутів + синхронний водоспад | 8 питань |
| 5. Справжній сигнал чи фейк | тренажер «Знайди фейк» | 8 питань |
| 6. Пеленгування та триангуляція | карта 2–4 постів, еліпс похибки 95 %, відбиття; калькулятор «дБм → км» | 10 питань |
| 7. Ворожі БпЛА | картки бортів із живим водоспадом, IQ-таймслоти, «Порівняти» | 40 питань (частина з водоспадом) |

Розділ «Тренування»: ідентифікація на час (рівні: базовий, 1–4 за методичкою — чисто, з цивільними завадами, два борти, IQ-таймслоти), підсумковий іспит (20 випадкових питань з усіх модулів), статистика за темами з помилками.

## Структура

- `lib/signal_engine/` — генератор синтетичних сигналів на чистому Dart, БПФ, робота в ізоляті.
- `lib/rendering/` — водоспад (кільцевий буфер → `decodeImageFromPixels`), спектр, палітри.
- `lib/features/` — екрани модулів.
- `assets/lessons/*.md` — тексти уроків. Їх можна редагувати без зміни коду.
- `assets/quizzes/*.json` — тести у форматі `{q, options, answer, explain, topic}`.
- `assets/atlas/signals.json` — тексти карток атласу.
- `assets/uav_profiles.json` — профілі бортів (Додаток А методички від 28.05.2025): види каналів, примітиви генератора, таблиці, факти з джерелами `М` / `М?` / `ВД`, IQ-режими, комбінації для «Ідентифікації». Генерується скриптом `tool/gen_profiles.py`; щоб додати борт, достатньо дописати профіль.
- `tool/gen_enemy_quiz.py` — генерує тест «Ворожі БпЛА».

Примітиви генератора для профілів: `fsk2_horns`, `fhss_random`, `fhss_rows`, `mfsk_trapezoid`, `ofdm_block` (опції `bump`, `notch` — поділ навпіл, `unevenRatio`, TDMA-маска `mask`, `hopEvery`, `widthEvery`), `analog_video`, `lora_chirp`, `mobile_burst`, `wifi_hump`, `bt_hops`, `microwave_teeth`, `cw`. Поведінка: `powerJumpDb` / `jumpEvery`, `modeEvery` (пік ↔ ППРЧ), мультиканальність через кілька сегментів `lo*/hi*`.
