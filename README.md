# Мульти-ринок ШІ Скальп-бот (BingX)

Мобільний застосунок (React + Capacitor) для автоматичної скальп-торгівлі
золотом, криптою та іншими парами через **BingX** (USDT-M Perpetual Swap
API) з плечем 20x. Рішення про вхід приймає ШІ **DeepSeek** за стратегією
Smart Money Concepts, розмір ставки росте драбиною разом із балансом
рахунку, а кожна угода лягає в журнал — раз на два дні бот сам аналізує,
що спрацювало, а що ні, і робить висновки на майбутнє.

⚠️ **Це реальна торгівля реальними коштами.** Замовлення відправляються на
біржу одразу після сигналу ШІ (перемикач "LIVE" у налаштуваннях можна
вимкнути, щоб бот тільки рахував сигнали без відправки ордерів).

## Можливості

- **Два екрани**: "Торгівля" (графік, живі позиції, статус ШІ) і "Журнал"
  (історія угод, вінрейт, ШІ-розбір раз на 2 дні).
- **Ринки**: BTC, ETH, SOL і золото (через PAXG-USDT — токенізоване золото;
  BingX не надає скриптований класичний XAUUSD на цьому API).
- **Драбина ставок**: маржа на угоду зростає разом із балансом рахунку
  (`constants.ts` → `STAKE_LADDER`, стартує з $2).
- **Плече 20x** за замовчуванням (`Налаштування → Плече`).
- **Журнал угод**: кожна закрита угода (по TP/SL чи вручну) записується з
  причиною входу від ШІ, сетапом, результатом.
- **Самонавчання**: у кожен запит до ШІ на новий сигнал підмішується
  статистика журналу (вінрейт, розбивка по сетапах) і висновки з останнього
  ретроспективного розбору — бот щодня "бачить" свою історію.
- **Розбір раз на 2 дні**: окремий виклик ШІ аналізує всі угоди за період і
  формулює конкретні правила на майбутнє; можна запустити вручну кнопкою
  "Аналізувати зараз" у Журналі.

## Запуск локально

**Залежності:** Node.js

1. `npm install`
2. Запустити: `npm run dev`
3. У застосунку відкрити ⚙ Налаштування і вказати:
   - **BingX API Key / Secret** — створіть на bingx.com з правом торгівлі
     на Perpetual Futures (без права виводу коштів).
   - **DeepSeek API ключ** — для аналізу сигналів і журналу.
   - **Плече** (за замовчуванням 20).
   - Перемикач **LIVE** — вимкніть, якщо хочете спершу просто подивитись,
     які сигнали видає ШІ, без реальних ордерів.

## Збірка під Android

```
npm run cap:add:android   # один раз
npm run cap:build         # build + cap sync
npm run cap:open          # відкрити в Android Studio
```

## Архітектура

- `services/bingx.ts` — підписаний HMAC-SHA256 клієнт до BingX Swap API
  (баланс, контракти, свічки, позиції, плече, ордери). Підпис рахується на
  пристрої (Web Crypto), секретний ключ нікуди не надсилається, крім самої
  біржі.
- `services/aiTrader.ts` — промпти й виклики DeepSeek: живий скальп-сигнал
  та ретроспективний розбір журналу.
- `services/journal.ts` — журнал угод, статистика, розклад розбору раз на
  2 дні, локальний трекінг відкритих угод (localStorage).
- `App.tsx` — опитує BingX (баланс/позиції/свічки), ротаційно сканує пари
  через ШІ, виконує вхід/вихід і веде журнал.

`bridge/` — застарілий MT5-міст (Python) з попередньої ітерації проєкту
(робота через MetaTrader5 для форекс/золота); поточна версія бота працює
напряму через BingX API і цей міст більше не задіяний.
