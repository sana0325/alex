# FitLife ⚡ — Вітаю, мій друже

Android-додаток для тренувань вдома без тренажерів:
- анкета (вага, здоров'я, звички) → персональна програма
- 7-денний цикл тренувань з таймером, голосом і генеративною епічною музикою
- харчування: калорії, БЖВ, меню з порціями в грамах
- програми відновлення (нікотин, алкоголь, речовини, солодке, сон, енергетики) + SOS
- 30-денний психологічний курс, сеанси самонавіювання під симфонічну музику, бібліотека

APK збирається GitHub Actions і публікується в Releases.
